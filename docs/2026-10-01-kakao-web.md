# 2026-10-01 웹 카카오 지도 연결

요청: 전달된 키로 로컬 카카오 지도 확인 및 추후 웹 배포 가능 여부 확인.

결정: Expo의 플랫폼 파일 해석으로 웹 전용 JavaScript SDK 공급자를 연결하고 native 도식 지도와 `RouteMapProps` 계약을 공유한다. SDK 모듈과 DOM 접근은 웹 파일에만 둔다. 키는 git 제외 `.env.local`에서 읽고 코드·문서에는 실제 값을 넣지 않는다.

웹은 카카오 배경 위에 시연 Polyline·출발/도착·모의 러너를 표시한다. SDK 실패 시 현재 origin과 재시도 및 사용자가 선택하는 도식 지도 전환을 제공한다. 코스 geometry와 환경 지표는 여전히 더미다.

실제 로컬 요청은 카카오 서버의 HTTP 401 `domain mismatched`로 거절되었다. 허용 origin 등록 후 타일 렌더링 확인이 남았다. 자동 테스트는 SDK를 모사하며 실제 인증 성공으로 보고하지 않는다. 설정·검증 결과는 [카카오 지도 가이드](KAKAO-MAPS.md)에 기록했다.

추가 수정: native export 출력을 `dist/ios`, `dist/android`로 분리해 웹 export를 보존한다. 기존 시연 E2E 4개와 지도 경계 E2E 6개, 앱 검사와 세 플랫폼 export를 통과했다.
