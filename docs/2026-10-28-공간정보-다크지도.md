# 팀 공간정보를 사용하는 다크 지도

2026-10-28. `RouteMapProps`를 유지하면서 기본 지도 공급자를 `TerrainRouteMap`으로 바꿨다. 웹·iOS·Android가 같은 SVG·래스터 자료를 사용한다. 카카오 배경은 `EXPO_PUBLIC_MAP_STYLE=kakao`로 명시적으로 선택할 수 있다.

## 사용 자료와 표시

이번 Notion MCP 조회는 접근 오류(404)를 반환했다. 새 첨부를 받았다고 간주하지 않고, 이전 작업에서 받은 `server/data/raw/` 원본 zip을 직접 읽었다. 출처 페이지는 [데이터 저장소](https://app.notion.com/p/3e78ae567af28033b190ea17aae5409b)이며 이전 확인 내용은 [PACE 자료 기록](2026-10-27-pace-실데이터-서버.md)에 있다.

| 원본                                                      | 지도 표시                                                                          |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `verified_yongsan_roads.zip`                              | 팀 도로망 4,426개. 표시용 2m 단순화, 도로별 `slope_mean` 사용                      |
| `yongsan_slope_preprocessing.zip`의 `보간.tif`·`보간.prj` | 약 5m DEM에서 계산한 어두운 표고·음영 래스터. 원본은 확장자와 달리 ESRI ASCII 형식 |
| 같은 zip의 `등고.shp`·`등고.prj`                          | 실제 등고선. 표시용 5m 단순화                                                      |
| `streetlight_park_preprocessing.zip`                      | 용산구와 주변 400m 안 공원 도형 75개                                               |
| `base_network_signal.zip`                                 | 실제 용산구 행정경계                                                               |

DEM·등고선의 원본 좌표계는 Korean 1985 / Modified Central Belt(Bessel, 원본 WKT의 EPSG:5174 표기)다. 도로·공원·경계의 EPSG:5186과 구분해 각 원본 WKT로 재투영한다. 화면은 EPSG:3857이며, 코스 GeoJSON 계약은 계속 EPSG:4326 `[경도, 위도]`다. 벡터·DEM·코스에 같은 투영과 원점을 적용한다.

DEM은 원래 약 5m 자료를 지도 표시용 1,400px 폭으로 재표본화한 음영이다. 무자료 셀은 투명하게 두고 지형을 만들어 채우지 않는다. 도로 색은 평균 지형 경사 `<5% / 5–10% / ≥10% / 미측정`이며, 도 단위 `slope_mean`을 `tan(도) × 100`으로 변환한다. 노면 경사나 실제 안전을 보장하는 지표가 아니다. 표시 도로망에는 통행 제한 구간도 포함되며, 실제 추천의 통행 가능 여부는 서버가 따로 판정한다.

검은 녹색 바탕·지형 음영·등고선·공원·경사별 도로 위에 라임색 선택 코스와 옅은 대안 코스를 표시한다. `지형 / 도로망 / 경사` 레이어, 드래그 이동, 확대·축소, 선택 코스 맞춤, 전체 후보 맞춤, 출발·도착, 모의 주행 위치를 지원한다. 배경이 실자료여도 `is_mock` 코스는 계속 `더미 코스`로 표시한다. 공간정보가 없는 용산구 주변은 바탕색으로 남는다.

## 재생성과 실행

```sh
cd server
.venv/bin/python -m dalro_api.map_assets
cd ..
npm run web -- --clear
```

생성기는 DB에 접근하거나 추천 코스를 변경하지 않는다. 원본 zip은 Git 제외를 유지하고, 표시용 파생 자료 `src/data/terrain-map.json`(약 443KB)과 `assets/maps/yongsan-relief.png`(약 311KB)를 앱에 번들한다. JSON에는 도로망 버전, DEM 원본 WKT, 사용한 zip의 SHA-256을 기록한다. 팀 자료가 바뀌면 재생성 후 앱을 다시 빌드해야 한다. 가로등·신호등 등 시설 개별 레이어와 전국 지도는 이번 범위에 포함하지 않는다.

기존 실행 중인 Expo에는 이전 번들이 남을 수 있으므로 `--clear`로 재시작한다. 환경 변수 없이 기본 공간정보 지도가 열린다. `EXPO_PUBLIC_MAP_STYLE=kakao`일 때만 기존 키·SDK·개발 빌드 설정을 적용한다. `hybrid` 데이터 모드는 그대로 PACE 서버 추천을 사용한다.

## 검증

투영 기준점·모바일/데스크톱 코스 범위·빈 좌표·확대 한계·원본 메타데이터를 앱 단위 테스트로 검사한다. DEM 행 순서·무자료 값·PNG 크기/투명도/CRC는 서버 테스트로 검사한다. 웹 E2E는 실제 번들 지도에서 레이어·확대·드래그·코스 선택·상세 진입을 검사한다. 실제 기기 렌더링과 native APK/IPA 빌드는 별도 확인이 필요하다.

- `npm run check`: 타입·lint·앱 테스트 67개·자료 계약·명령 가드 통과.
- 서버 pytest: 22개 통과.
- 웹·iOS·Android JS export 통과. APK/IPA 빌드나 실제 기기 검증은 아니다.
- `EXPO_OFFLINE=1 npx expo install --check`: 로컬 의존성 일치. 오프라인 검사이므로 원격 버전 조회는 하지 않았다.
- Chrome Playwright: 모바일·데스크톱 합계 16개 통과. 기본 공급자가 공간정보 지도라 카카오 전용 6개는 기존 조건에 따라 건너뛰었다. 카카오 모드의 재검증은 이번 범위에서 수행하지 않았다.
