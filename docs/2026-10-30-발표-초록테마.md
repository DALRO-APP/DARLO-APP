# 발표 자료 초록 테마

기존 발표 슬라이드와 개별 요소의 파란 강조색을 초록 계열로 바꿨다. 앱 테마 변경이 아니라 발표 산출물의 테마 변경이다.

## 팔레트와 범위

- 메인 초록: `#208044`.
- 추천 1·2·3: 초록 `#208044`, 올리브 `#849E20`, 딥그린 `#124B35`. 기존 번호·레이블을 유지한다.
- penalty 순차 범례: `#B0D991` → `#67AE55` → `#287D42` → `#124B35`. 값이 클수록 짙게 표시한다.
- 강조 카드 배경: `#EFF7E9`, 투명 요소의 강조 면은 초록 7% 알파.
- 기존 앱 캡처 5개는 라임 테마여서 원본을 그대로 복사했다.

원본 `plots.py`, `elements.py`, `data.json`, 앱 캡처를 이전 작업 임시 폴더에서 프로젝트의 산출물 폴더로 복사했다. 도식·지도·차트는 Python 렌더링 코드의 색상 토큰을 바꿔 다시 생성했다. 생성형 이미지 편집은 사용하지 않았다. 색상에 관한 설명인 '파란 점'도 '초록 점'으로 맞췄다.

## 전달 파일

`artifacts/DALRO-발표-초록테마/`에 저장하며 Git에서 제외한다. 기존 파란 자료 폴더는 보존한다.

- `PNG/`: 투명 PNG 24개.
- `SLIDES/`: 1920×1080 PNG 슬라이드 10장.
- `DALRO_초록테마_슬라이드.pptx`: 슬라이드 PNG를 배치한 10장 파일. 텍스트·차트는 이미지이며 별도 개체 편집은 개별 PNG를 사용한다. Office 테마 강조색과 하이퍼링크 색도 초록 계열이다.
- `DALRO_초록테마_투명PNG.zip`: 개별 요소 24개.
- `DALRO_초록테마_발표자료_전체.zip`: 슬라이드·개별 요소·PPTX·미리보기·팔레트·검사 목록.
- `미리보기.html`, `palette.json`, `manifest.json`, `README.md`.
- `source/`: 재생성용 코드·원본 데이터·캡처. 다운로드 ZIP에는 포함하지 않는다.

## 재생성과 검증

임시 Python 가상환경에 `matplotlib`, `python-pptx`, `Pillow`, `numpy`를 설치하고 아래 순서대로 실행한다. 원래 사용한 SCDream 글꼴 경로는 `source/plots.py`의 `font()`에 있다.

```sh
python artifacts/DALRO-발표-초록테마/source/plots.py
python artifacts/DALRO-발표-초록테마/source/elements.py
python artifacts/DALRO-발표-초록테마/source/package.py
```

- 원본 `data.json` 바이트 일치: 발표 수치의 재계산·변경 없음.
- 요소 24개 모두 RGBA·알파 범위 0~255이며 원본과 해상도가 같다.
- 앱 캡처 5개는 이전 투명 PNG와 바이트가 같다.
- 슬라이드 10개 모두 1920×1080.
- ZIP CRC 검사 및 모든 항목의 원본 바이트 일치.
- PPTX를 다시 읽어 10장 확인. PowerPoint 앱에서 직접 열어보는 검증은 하지 않았다.
- 파이프라인·추천 경로·Cost 비교 슬라이드와 penalty 지도는 이미지로 확인했다.

앱 소스·서버·배포를 변경하지 않았으므로 앱 테스트와 네이티브 실기 검증은 이번 작업 범위에 없다.

## Notion 반영

학교 계정 연결로 [DALRO - 앱 구현 상황](https://app.notion.com/p/4098ae567af280c299a5e28367249f33)에 반영했다.

- 슬라이드 이미지 10개와 개별 요소 19개를 초록 버전으로 교체하고, 앱 캡처 5개는 기존 첨부를 유지했다.
- 전체 ZIP·개별 요소 ZIP·PPTX 다운로드 3개를 첨부했다. 전송한 32개 파일 모두 업로드 완료 상태와 원본 크기를 확인했다.
- 발표 한 줄 콜아웃 6개의 배경을 초록으로 바꾸고, 파란 테두리 설명을 초록으로 맞췄다.
- 처음 이미지 주소만 교체한 요청은 `no_match` 경고로 이미지에 적용되지 않았다. 현재 본문을 다시 읽고 모든 설명·표·구조를 보존한 전체 콘텐츠로 이미지 블록을 교체했다. 최종 저장은 오류·경고 없이 완료됐다.

기존 로컬 파란 자료와 이전 전달 기록은 남겨 두며 커밋·push는 하지 않았다.
