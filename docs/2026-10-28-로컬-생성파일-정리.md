# 로컬 생성 파일과 의존성 정리

2026-10-28. Git 변경 목록의 로컬 캐시와 실제 의존성 변경을 구분해 정리했다.

- `.gradle/`, `.kotlin/`, 로컬 카카오 모듈의 `android/build/`는 캐시·산출물이므로 Git에서 제외한다. 디스크의 캐시는 삭제하지 않는다. 모듈의 Kotlin·Swift·Gradle 설정 등 원본 소스는 계속 추적한다.
- Expo 자동 생성 파일 `expo-env.d.ts`는 기존 추적을 해제하고 ignore한다. 로컬 파일은 보존하며, 항상 필요한 `expo/types` 참조는 `src/types/expo.d.ts`로 옮긴다. Expo를 아직 실행하지 않은 체크아웃에서도 타입 검사가 가능하다.
- 기존 `package.json`·`package-lock.json`의 TypeScript 5.9 → 6.0.3 변경은 생성 캐시가 아닌 실제 의존성 변경이므로 ignore하지 않는다. 현재 사용 중이며 앱 검사 70개와 플랫폼 JS export가 통과한 버전을 두 파일에 함께 기록한다.
- 생성 `expo-env.d.ts`를 임시로 제외한 상태에서 `npm run typecheck` 통과. `EXPO_OFFLINE=1 npx expo install --check`는 로컬 SDK 의존성 일치로 통과했다. 원격 버전 조회는 하지 않았다.
