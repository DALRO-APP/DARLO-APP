# PACE 실데이터 추천 서버

2026-10-27. 노션 '26-1 종합설계 › 데이터 저장소'의 팀 전처리 자료로 PACE 추천을 구현했다. 서버는 FastAPI + SQLAlchemy + SQLite이며 [server/](../server/README.md)에 있다. 앱은 `hybrid` 모드에서 PACE만 서버로 보낸다. POWER·NIGHT·GREEN은 계속 더미다.

## 사용한 노션 자료

Notion MCP로 페이지와 첨부를 직접 받아 확인했다. 원본은 `server/data/raw/`에 두며 커밋하지 않는다.

## 확인한 사실

- **경사 단위는 도(°)다.** `보간.tif`(5m DEM, ESRI ASCII)에서 Horn 경사를 다시 계산했다. `경사.tif`와 도 기준 중앙 오차 0.000005, % 기준 4.1이다. 앱 계약은 %라서 `tan(°)×100`으로 바꾼다. 값은 도로 구역의 지형 경사 평균이다. 산비탈 도로(남산 20~30%)에서는 노면 경사보다 크게 나온다. 앱에는 "평균 지형 경사"로 표시한다.
- **`signal_cnt`·`cross_cnt`의 0은 측정값이다.** 10m 버퍼 결합에서 시설이 없을 때 생긴 NULL을 0으로 바꾼 것이다. 결측이 아니다. 앞서 계약(미측정 null)과 다르다고 본 판단을 정정한다.
- **팀 PACE 비용식을 그대로 재현했다.** `stop_norm` 4,426개가 cost.zip과 최대 0.0023 차이로 일치한다. cost.zip의 `fid`는 서울 전체 번호라서, 행 순서와 `osm_id`·길이로 맞췄다.
- 검증 도로망에는 자동차 전용 도로가 없다. `busway` 14개만 통행 불가로 둔다.

## 결정

1. **탐색 그래프는 OSM 공유 꼭짓점에서 나눈다.** 결과는 9,276개 구간, 6,906개 노드다. `edge_id`는 `{팀 fid}-{순번}`이다. 꼭짓점을 공유하지 않는 고가·지하 도로는 평면 교차만으로 연결하지 않는다.
2. **시설 수는 원본 위치로 다시 센다.** 피처 단위 개수를 구간에 그대로 복사하면 교차로 시설이 여러 번 세어진다. 그래서 팀과 같은 10m 버퍼로 구간·코스별 고유 시설을 센다. 비용식의 `stop_norm`은 팀 피처 값을 쓴다.
3. **용산 미군기지 내부 도로를 제외한다.** 영문 도로명(X Corps Boulevard 등) 구간의 concave hull 1.31km² 안 646개 구간을 `walkable=false`로 둔다. 한글 이름 공공 도로는 영역 안이어도 남긴다. 가족공원·박물관·이촌 출발점은 영역 밖임을 확인했다. 이 처리 전에는 용산가족공원 출발 코스가 기지 내부를 지났다.
4. **남산 둘레길 시연 좌표를 옮겼다.** 국립극장 방면 `[126.995, 37.546]`은 중구라서 용산구 도로망 50m 밖이다. 차량이 통제되는 남측순환로 약수터 부근 `[126.9992, 37.547]`(스냅 1.5m)로 바꿨다. mock 코스 ID는 장소 ID 기반이라 기존 URL이 그대로 열린다.
5. **PACE에서는 계단을 제외한다.** 경사 미측정 구간에는 최대 경사 페널티를 준다. 팀 가중치 0.83/0.17, α=3, 상한 0.275는 그대로 쓴다.
6. **Loop는 삼각 경유 탐색을 쓴다.** 12방위 × 반경 보정, 앞 구간 재사용 비용 4배, 반복 구간 30% 이하, 서로 다른 후보 3개다. Straight는 PACE 최소 비용 경로와 대안 경로다. 목표 거리를 만들 수 없으면 `courses: []`를 반환하고, 앱은 빈 결과 화면을 보여준다.
7. **`GET /v1/courses/{id}`는 SQLite에 보관한 코스를 반환한다.** 서버를 재시작해도 상세 URL이 열린다. ID는 도로망 버전·알고리즘·주야간·edge 순서의 해시다.
8. **앱은 `hybrid` 모드로 목적별 저장소를 고정한다.** 장애 시 대체가 아니다. 서버 코스(`is_mock: false`)에는 서버가 계산한 근거 문장과 실데이터 안내를 표시한다.

## 검증

- 서버 pytest 14개가 통과했다(합성 격자: 계약 형태, 큰길 회피, 재시작 후 조회, 편도 도착, 422/404/501, 빈 결과).
- 실데이터 전달 묶음(`python -m dalro_api.export`)이 앱 검사기 `scripts/validate-data.ts`에서 PASS했다(도로 9,276개, 추천 6개).
- 시연 출발지 3곳 × 3/5/8/10km Loop가 모두 ±10% 안에 1~3개 나온다. 요청당 0.06~0.3초다.
- `hybrid` 웹 export + uvicorn을 Chrome으로 확인했다. PACE 추천 3개(5.1/4.7/4.7km), 상세 직접 진입 시 `GET` 200, 모의 러닝 시작, POWER 더미 유지, 페이지 오류 0건.

## 팀에 확인할 점

- `stop_den` 상한 0.275는 m당 시설 수다. 일반 도로의 페널티가 매우 작아서 환경 점수가 89~98에 몰린다. 시설 하나는 약 9m 우회 비용에 해당한다(α=3). km당 밀도나 백분위 기반 정규화를 검토해 주세요.
- `slope_mean`은 지형 경사다. 노면 경사가 필요하면 도로 중심선을 따라 DEM을 샘플링해서 구간 경사와 상승량을 계산해야 한다.
- 가로등은 서울시 관리분뿐이다(구청 관리분 없음). 야간 PACE의 조명 가중치는 팀에서 정하지 않아 비용에 넣지 않았고, 개수만 표시한다.
- 기지 영역은 휴리스틱이다. OSM `access`·`landuse=military`를 전처리에 포함하면 더 정확해진다.
- 공원 수(`park_cnt`)는 녹지 비율이 아니라서 `green_ratio`는 null로 둔다.
